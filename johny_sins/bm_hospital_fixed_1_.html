📧 Email Notification Setup

Configure Gmail alerts for doctors & patients via EmailJS (free)

⚠️ Not configured – emails will not be sent
📋 Setup Guide (5 minutes, free)
1Create a free EmailJS account
Go to www.emailjs.com → Click Sign Up Free → Verify your Gmail.
2Add Gmail as an Email Service
Dashboard → Email Services → Add New Service → Choose Gmail → Connect your account → Click Create Service.
Copy the Service ID (e.g. service_abc123) and paste it below.
3Create Template 1 – Doctor Booking Notification
Dashboard → Email Templates → Create New Template
Subject: New Appointment – {{patient_name}} on {{date}}
Body:
Dear {{doctor_name}},
Patient: {{patient_name}} | Phone: {{patient_phone}}
Date: {{date}} at {{slot}} | Dept: {{dept}}
Reason: {{reason}} | ID: {{booking_id}}
Set To Email field to: {{doctor_email}}
Save → copy the Template ID (e.g. template_abc123).
4Create Template 2 – Patient Cancellation Notification
Create another template:
Subject: Appointment Cancelled – {{booking_id}}
Body:
Dear {{patient_name}},
Your appointment with {{doctor_name}} ({{dept}}) on {{date}} at {{slot}} has been cancelled.
Reason: {{cancel_reason}} | Cancelled on: {{cancel_on}}
Please call +91 44-2600-1234 to reschedule.
Set To Email field to: {{patient_email}}
Save → copy the Template ID.
5Get your Public Key
Dashboard → top-right menu → Account → API Keys tab → copy Public Key.
