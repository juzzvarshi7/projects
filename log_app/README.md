# Daily Reflection App

## Description
This is a Flask-based web application for tracking daily reflections, allowing users to log their emotional state, activities, social interactions, and personal reflections.

## Features
- User authentication (Login and Registration)
- Daily reflection logging with dropdown options for emotional state
- Dashboard to view logged reflections
- Responsive UI using Bootstrap
- Data visualization for tracking trends over time (to be implemented)

## Requirements
- Python 3.x
- Flask
- Flask-SQLAlchemy
- Flask-WTF

## Installation

2. Navigate to the project directory.
